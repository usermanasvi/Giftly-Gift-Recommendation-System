# Giftly – Gift Recommendation System

Giftly is a web-based gift recommendation system developed using PHP and MySQL.

## Features

- User-friendly gift recommendation form
- Recommendations based on person, age, occasion, budget and interest
- Product images
- Product descriptions and prices
- Match score for recommendations
- Amazon and Flipkart purchase options
- MySQL database integration

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP
- phpMyAdmin

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the `giftly` folder into the XAMPP `htdocs` folder.
4. Create a MySQL database named `giftly`.
5. Import/create the required tables.
6. Open:

http://localhost/giftly/

## Project

Giftly helps users find suitable gifts based on their preferences.
